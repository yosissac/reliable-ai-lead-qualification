# Roadmap

## Near Term

- add a containerized integration-test runner for CI;
- parameterize thresholds and rubric versions without editing workflow code;
- add OpenTelemetry-compatible execution and provider metrics;
- publish a neutral 60–120 second demonstration video;
- add migration files separate from first-install database initialization.

## Evaluation Track

- assemble an expert-labeled, privacy-safe benchmark dataset;
- measure qualification agreement, calibration, false-HOT and false-COLD costs;
- compare model families under identical schemas and prompts;
- run adversarial prompt-injection experiments against real models;
- measure latency, token use, and total cost per completed lead;
- test demographic and linguistic slices for systematic error;
- evaluate human-review policies for WARM and low-confidence cases.

## Product Track

- optional CRM adapters for HubSpot, Salesforce, Pipedrive, and Zoho;
- approval queue and reviewer feedback capture;
- configurable Slack, Teams, and email destinations;
- operational dashboard and reconciliation tooling;
- retention/deletion automation;
- reusable deployment profiles for managed container platforms.

Roadmap items are proposals, not claims of implemented functionality.
